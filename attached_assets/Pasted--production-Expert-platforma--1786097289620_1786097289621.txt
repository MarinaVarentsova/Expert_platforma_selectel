Работаем только в проекте Expert_platforma_selectel.

Ничего не изменять.

Ничего не исправлять.

Ничего не коммитить.

Нужен только технический аудит текущего production-кода после всех последних рефакторингов.

Все выводы делать только по фактическому состоянию кода.

Если факт нельзя установить — писать НЕ УСТАНОВЛЕНО.

Цель аудита

Подтвердить, что после удаления Supabase, Vercel, OpenAI и локализации Google Fonts в production не осталось реально исполняемых внешних зависимостей и трансграничных потоков данных.

1. Production runtime

Построй фактическую карту production-вызовов.

Покажи только реально выполняемые вызовы.

Для каждого укажи:

endpoint;
hostname;
provider;
какие данные передаются;
frontend или backend инициирует вызов;
LIVE / DEAD CODE / DEV ONLY.

Не перечисляй зависимости, которые не могут выполниться в production.

Повтори аудит только следующих интеграций:

старые Storage;

осталась dependency;
остался config;
остался lockfile;
осталась миграция;
остался dead code;
может ли реально выполниться.
3. Трансграничные передачи

Проверь только production.

Найди любые реальные передачи пользовательских данных за пределы российской инфраструктуры.

Учитывай только реально выполняемые HTTP/WebSocket/API вызовы.

Не учитывать:

комментарии;
README;
lock-файлы;
старые SQL;
тесты;
dead code.

Для каждого найденного потока укажи:

какие данные уходят;
куда уходят;
при каком действии пользователя.

Если потоков нет — написать:

ТРАНСГРАНИЧНЫЕ ПЕРЕДАЧИ В PRODUCTION НЕ ОБНАРУЖЕНЫ.
