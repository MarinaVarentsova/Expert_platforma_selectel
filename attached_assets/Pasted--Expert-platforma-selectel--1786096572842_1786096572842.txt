убрать внешние обращения браузера к Google Fonts и перевести используемые шрифты на локальную загрузку из самого приложения.

это ТОЛЬКО инфраструктурная замена источника шрифтов.

==================================================
1. СНАЧАЛА ПРОВЕРИТЬ ТЕКУЩИЕ ШРИФТЫ
==================================================

Найти все обращения к:

fonts.googleapis.com
fonts.gstatic.com

Отдельно определить:

- какие font-family используются;
- какие font-weight реально используются;
- в каких файлах они подключены.

По текущему аудиту ожидаются:

- Inter
- Plus Jakarta Sans

Но сначала подтвердить это по коду.

Не менять CSS typography.

==================================================
2. ЛОКАЛИЗОВАТЬ ТОЛЬКО НЕОБХОДИМЫЕ ШРИФТЫ
==================================================

Для каждого реально используемого шрифта добавить локальные файлы .woff2.

Разместить их внутри статических ресурсов приложения, например:

public/fonts/

Использовать только необходимые веса.

Не подключать новые шрифты.
Не менять семейства.

==================================================
3. СОХРАНИТЬ ТЕКУЩУЮ ТИПОГРАФИКУ
==================================================

Через @font-face настроить те же:

- font-family;
- font-weight;
- font-style.

Существующие CSS:

font-family: "Inter"
font-family: "Plus Jakarta Sans"

не переписывать без необходимости.

То есть компоненты приложения вообще не должны знать, что источник шрифта изменился.

Меняется только:

БЫЛО:
браузер → Google Fonts

СТАЛО:
браузер → локальный файл внутри приложения.

==================================================
4. УДАЛИТЬ ТОЛЬКО ВНЕШНЕЕ ПОДКЛЮЧЕНИЕ GOOGLE
==================================================

После того как локальные шрифты подключены и работают, удалить:

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" ...>

и stylesheet ссылки вида:

https://fonts.googleapis.com/...

Не удалять другие <link>.
Не менять favicon.
Не менять meta.
Не менять внешние ссылки бизнес-сайта.

==================================================
5. ОСОБО ПРОВЕРИТЬ palata-promo
==================================================

Если public/palata-promo/index.html использует Plus Jakarta Sans через Google Fonts:

также перевести его на локальный файл.

Не менять HTML-разметку promo.
Не менять дизайн promo.
Не менять размеры элементов.

==================================================
6. ВИЗУАЛЬНАЯ ПРОВЕРКА
==================================================

После изменения убедиться, что визуально ничего не изменилось.

Проверить:

- Customer Dashboard;
- Expert Dashboard;

- Admin;

Особенно проверить:

- высоту элементов;

- таблицы;
- карточки;
- меню.

Если локальный вариант шрифта визуально отличается от текущего —
НЕ продолжать рефакторинг, а исправить подключение/вес шрифта.

==================================================
7. ПРОВЕРКА ФУНКЦИОНАЛА
==================================================

Запустить:

tsc --noEmit
все существующие тесты.

Дополнительно убедиться, что браузеру больше не требуется сеть Google для отображения шрифтов.
