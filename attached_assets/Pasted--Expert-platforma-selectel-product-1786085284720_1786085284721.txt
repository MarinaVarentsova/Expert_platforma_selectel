Работаем ТОЛЬКО в репозитории Expert_platforma_selectel — приложение Палаты.

Контекст:
- production Палаты работает в Selectel/Coolify;
- AI вызывается только через AI Gateway;
- AI Gateway уже работает через Yandex AI;
- прямых запросов Палаты к api.openai.com нет;
- OPENAI_API_KEY в Палате не используется;
- Vercel-код уже удалён отдельным коммитом.

ЗАДАЧА:
полностью удалить из приложения Палаты остатки OpenAI-специфичного кода, названий, переменных и документации.

ВАЖНО:
НЕ менять фактическую работу AI.
НЕ менять AI Gateway.
НЕ менять Yandex.
НЕ менять system prompt.
НЕ менять базу знаний.
НЕ менять confidence threshold.
НЕ менять алгоритм определения направления.
НЕ менять frontend.
НЕ менять API-контракты.
НЕ менять Auth.
НЕ менять PostgreSQL.
НЕ менять бизнес-логику создания заказа.

Палата после этой задачи должна по-прежнему обращаться:

Palata
→ AI_GATEWAY_URL
→ AI Gateway
→ Yandex

- или это просто старое имя переменной вокруг AI Gateway.

==================================================
2. НЕ ТРОГАТЬ AI GATEWAY
==================================================

Оставить:

AI_GATEWAY_URL
AI_GATEWAY_TOKEN

Оставить текущий запрос:

fetch(AI_GATEWAY_URL, {
  headers: {
    "x-api-key": AI_GATEWAY_TOKEN
  }
})

Не менять формат body, который ожидает Gateway.

Даже если body имеет OpenAI-compatible формат:

{
  model,
  messages,
  temperature,
  response_format
}

НЕ считать это прямой зависимостью от OpenAI.

Это контракт нашего AI Gateway.

==================================================
3. УБРАТЬ OPENAI_API_KEY
==================================================

Найти:

OPENAI_API_KEY

Если production-код его нигде не читает:
- удалить из .env.example;
- удалить из docs;
- удалить startup-логи;
- удалить комментарии.

Не добавлять новый fallback.

==================================================

==================================================

openAiResponse → gatewayResponse
openAiData → gatewayData

[AI-PROD] OpenAI response.status

[AI-PROD] AI Gateway response.status

[AI-PROD] AI Gateway HTTP status

[AI-PROD] OpenAI model
→
[AI-PROD] Requested model

Не менять данные и control flow.

==================================================
5. MODEL
==================================================

Проверить использование:

gpt-4o-mini

Если это значение отправляется только как поле model в AI Gateway и Gateway игнорирует/нормализует его для Yandex:

НЕ удалять автоматически.

Показать, зачем оно сейчас нужно.

Если это только исторический дефолт Палаты и Gateway от него не зависит:
предложить безопасное нейтральное имя/значение, но не менять без доказательства.

Главное — не сломать контракт Palata → Gateway.
