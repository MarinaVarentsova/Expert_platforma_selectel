Нужно внести только следующие изменения.

1. Убрать повторную локальную проверку текста при создании заказа

В обработчике POST /api/palata/requests:

- сохранить проверку, что expertise_direction_id совпадает с допустимым направлением;
- убрать использование checkLocalMarkers(description) как обязательного финального гейта;
- не возвращать 422 NO_CONSTRUCTION_MARKERS, если frontend уже получил валидный direction_id от /api/ai-detect-direction.

Финальная серверная проверка при создании должна быть:

- direction_id существует;
- direction_id совпадает с допустимым направлением;
- пользователь авторизован;
- обязательные поля валидны.

Не запускать второй независимый semantic/local анализ описания.

- Gateway недоступен;
- HTTP не 200;
- JSON невалиден;
- AI не определил направление.

4. Убрать fallback на Vercel

Было:

const gatewayUrl =
  process.env.AI_GATEWAY_URL ||
  "https://ai-gateway-core.vercel.app/api/chat";

Должно быть:

const gatewayUrl = process.env.AI_GATEWAY_URL;

if (!gatewayUrl) {
  return {
    status: "openai_error",
    error: "AI_GATEWAY_URL_MISSING"
  };
}

Никаких скрытых fallback URL.
