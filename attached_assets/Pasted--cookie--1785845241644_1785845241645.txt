Проведи полный технический аудит текущего проекта с точки зрения персональных данных, cookie, браузерного хранения и передачи данных сторонним сервисам.
Ничего в коде не меняй. Только исследуй весь проект: frontend, backend, конфигурацию, переменные окружения, зависимости, схему БД и инфраструктурные настройки, которые доступны тебе.
Ничего не предполагай. Если факт невозможно установить по проекту, пиши НЕ УСТАНОВЛЕНО.
Проверь:
COOKIE
Найди все cookie, создаваемые frontend, backend и сторонними библиотеками.
Для каждого укажи:
— имя;
— где создаётся;
— назначение;
— содержимое;
— срок жизни;
— HttpOnly;
— Secure;
— SameSite;
— домен;
— является ли технически необходимым.
Отдельно проверь document.cookie, Set-Cookie и библиотеки работы с cookie.
Если cookie нет — напиши прямо.
БРАУЗЕРНЫЕ ХРАНИЛИЩА
Проверь:
— localStorage;
— sessionStorage;
— IndexedDB;
— Cache Storage;
— другие локальные хранилища.
Для каждого ключа укажи, какие данные хранятся и зачем.
Особенно проверь, где хранятся access token, refresh token, JWT, ID пользователя, email, телефон и другие пользовательские данные.

— fetch;
— axios;
— WebSocket;
— SDK;
— iframe;
— script;
— beacon;
— внешние изображения;
— CDN;

— email/SMS-сервисы;

— мониторинг ошибок;
— AI/API;
— любые другие внешние сервисы.
Для каждого реально найденного сервиса укажи:
— название и домен;
— какие данные ему передаются;
— передаётся ли IP;
— передаются ли ФИО, email, телефон, ID пользователя, текст заявки или другие данные;
— в какой момент происходит передача.
Отдельно проверь, не осталось ли после разработки или миграций обращений к Vercel, Supabase, Firebase, Google, Cloudflare, Sentry и другим внешним платформам.
